¿Qué es geocodificar?

Convertir una dirección en coordenadas (latitud y longitud).

Sin coordenadas no hay análisis espacial: la geocodificación es el primer paso de los focos de transmisión activa y persistente.

Lo que vamos a hacer

  1. Entrar a Google Cloud Console con una cuenta de Gmail
  2. Crear un proyecto nuevo
  3. Activar la facturación (tarjeta de crédito o débito)
  4. Habilitar Geocoding API y Maps Static API
  5. Crear la clave de API
  6. Restringir la clave
  7. Guardar la clave en R y probarla

1 · Entrar a Google Cloud Console

  • Ir a console.cloud.google.com
  • Iniciar sesión con una cuenta de Gmail
  • La primera vez, aceptar los términos del servicio y elegir el país

Usa una cuenta institucional o personal que vayas a conservar: la clave queda ligada a esa cuenta.

2 · Crear un proyecto

  • En la barra superior, abrir el selector de proyectos
  • Clic en Proyecto nuevo
  • Nombrarlo, por ejemplo: geocodificacion-dengue-oaxaca
  • Clic en Crear y seleccionarlo en el selector

Un proyecto agrupa las APIs, las claves y la facturación. Conviene un proyecto por estado o por programa.

3 · Activar la facturación

  • Menú ☰ → Facturación → Vincular una cuenta de facturación
  • Registrar los datos y una tarjeta de crédito o débito
  • Google la usa para verificar la identidad; dentro del uso gratuito mensual no se hace ningún cobro

Sin una cuenta de facturación activa, la Geocoding API responde con el error REQUEST_DENIED.

4 · Habilitar las APIs

Menú ☰ → APIs y servicios → Biblioteca

Buscar y dar clic en Habilitar en cada una:

API Para qué la usamos
Geocoding API Convertir los domicilios en coordenadas
Maps Static API Descargar mapas base de Google (ggmap)

5 · Crear la clave de API

Menú ☰ → APIs y servicios → Credenciales

  • Clic en + Crear credenciales → Clave de API
  • Copiar la clave que aparece (empieza con AIza…)
  • Clic en Editar clave de API para restringirla (siguiente paso)

La clave es como una contraseña ligada a tu tarjeta: no la compartas, no la pongas en una diapositiva ni la subas a GitHub.

6 · Restringir la clave

En la página de la clave:

  • Nombre: algo reconocible, por ejemplo clave-geocoding-r
  • Restricciones de la API → Restringir clave → marcar solo:
    • Geocoding API
    • Maps Static API
  • Guardar

Con la clave restringida, si alguien la obtiene solo puede usar esas dos APIs. Las restricciones por dirección IP no conviene usarlas en laptops que cambian de red.

Costos y límites

  • La Geocoding API y la Maps Static API están en la categoría Essentials de Google Maps Platform
  • Cada servicio Essentials incluye 10,000 solicitudes gratuitas al mes; después se cobra por cada mil solicitudes
  • Recomendado:
    • Facturación → Presupuestos y alertas: crear una alerta (p. ej. 1 USD) para recibir un correo si hay cargos
    • APIs y servicios → Geocoding API → Cuotas: limitar las solicitudes por día

Precios vigentes: developers.google.com/maps/billing-and-pricing

7 · Guardar la clave en R

Nunca escribas la clave dentro del script. Guárdala en el archivo .Renviron:

# Abre el archivo .Renviron de tu usuario
usethis::edit_r_environ()

Agrega estas dos líneas (con tu clave), guarda y reinicia R:

GGMAP_GOOGLE_API_KEY=AIza...tu_clave...
GOOGLEGEOCODE_API_KEY=AIza...tu_clave...

La primera la usa ggmap y la segunda tidygeocoder.

Probar la clave

library(ggmap)
register_google(key = Sys.getenv("GGMAP_GOOGLE_API_KEY"))

# Geocodificar una dirección
geocode("Calle Hidalgo 204, San Felipe del Agua, Oaxaca de Juárez, Oaxaca, México")

# Mapa estático (Maps Static API)
get_googlemap(center = c(lon = -96.7135, lat = 17.0981), zoom = 15) |>
  ggmap()

Si regresa coordenadas y dibuja el mapa, la clave funciona.

Geocodificar con denhotspots

library(denhotspots)
ggmap::register_google(key = Sys.getenv("GGMAP_GOOGLE_API_KEY"))

# Vector de domicilios completos de la base del SINAVE
addresses <- paste(x$calle, x$numero, x$colonia, x$localidad,
                   "Oaxaca, México", sep = ", ")

# Geocodifica y va guardando el avance en un archivo .rds
geocoden(infile = "oaxaca_2026", address = addresses)

Si la sesión se interrumpe, al volver a correr geocoden() continúa donde se quedó.

Alternativa: tidygeocoder

library(tidygeocoder)

casos_geo <- casos |>
  geocode(address = direccion, method = "google")

Usa la variable GOOGLEGEOCODE_API_KEY del .Renviron y agrega las columnas lat y long a la tabla.

Buenas prácticas

  • Una sola vez por domicilio: guarda los resultados (saveRDS()) y no vuelvas a geocodificar lo mismo
  • Domicilios completos: calle, número, colonia, localidad, estado y país mejoran la precisión
  • Revisa la precisión: en la columna accuracy, street_address o premise es el domicilio; route, neighborhood o locality caen en la calle, la colonia o el centro de la localidad
  • Protege la clave: .Renviron fuera de GitHub; si se filtra, bórrala y crea otra en Credenciales

Errores comunes

Mensaje Causa probable Solución
REQUEST_DENIED API no habilitada o sin facturación Habilitar la API y vincular la facturación
API key not valid Clave mal copiada o borrada Revisar el .Renviron y reiniciar R
OVER_QUERY_LIMIT Se alcanzó la cuota Revisar las cuotas o esperar al día siguiente
ZERO_RESULTS Domicilio incompleto o con errores Corregir y completar la dirección
